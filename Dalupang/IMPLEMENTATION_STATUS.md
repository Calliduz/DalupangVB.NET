## ?? Troubleshooting

### Common Issues

**Q: Build fails with "ColorHelper is not a member"**  
A: Make sure to use `ColorHelper.Lighten()` not `EnterpriseDesignSystem.ColorHelper.Lighten()`. ColorHelper is in the EnterpriseUtilities module.

**Q: Form doesn't resize properly**  
A: Implement the Resize event and call AdjustLayoutForScreenSize(). See Form1 for example.

**Q: Theme colors not applying**  
A: Check if you're using the LightTheme/DarkTheme properties correctly. Call ApplyTheme() after changing theme.

**Q: Validation not working**  
A: Ensure you're checking `ValidationResult.IsValid` and handling the `ErrorMessage` property.

**Q: Animations are choppy**  
A: Enable double buffering: `Me.DoubleBuffered = True` and check animation FPS settings.
